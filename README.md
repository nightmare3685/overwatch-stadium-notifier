# Overwatch Stadium Notifier

PC版オーバーウォッチのスタジアムで、確認済みの②「マッチ成立音」または③「スタジアムだ！」を検知し、画面に表示するWindows用試作ツールです。①の待機開始音は登録していません。

現段階ではDiscordへの送信はありません。Webhookは不要です。

## 起動

64-bit Windows 11（Windowsビルド20348以降）とPython 3.10以降（Tkinter付き）が必要です。音声取得ヘルパーにはWindows付属の.NET Framework 4.xを使用します。

1. リポジトリをダウンロードし、ZIPなら展開します。
2. `start.bat` をダブルクリックします。初回は専用の `.venv` に依存パッケージを取得します（インターネット接続が必要）。
3. Overwatchを起動して「検知開始」を押します。`Overwatch.exe` を自動選択します。出力デバイスの選択は不要です。
4. 検知すると「マッチが見つかりました！」と時刻・対象音・一致度を表示します。
5. 「停止」またはウィンドウを閉じると監視を終了します。

手動起動:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## 検知の仕組みと設定

- Windowsのプロセス別WASAPIループバックで、Overwatchとその子プロセスの再生音だけを取得します。マイクは使用しません。
- 16 kHzモノラルに変換し、音の周波数パターンを登録済みのテンプレートと比較します。
- しきい値は初期値 `0.90`。表示される一致度は確率ではありません。下げると拾いやすくなりますが誤検知も増えます。
- ②または③のどちらかが一致すれば検知します。②の判定には約0.6秒、③には約4秒の音声が必要です。
- 検知後30秒は追加の通知表示を抑えます。停止・再開で抑制時間もリセットされます。
- 音声はメモリ内で処理し、監視中の録音保存・外部送信は行いません。
- YouTube・Discordなど別プロセスの再生音を除外します。ただしOW内のボイスチャットやBGMはOWの音声に含まれます。取得失敗時にPC全体の音へ切り替わることはありません。
- バックグラウンドでもゲームが音を出す設定が必要です。OWの終了を検知すると停止します。ゲーム再起動後は「検知開始」を押し直してください。
- 入力オーバーフローなどで音声に欠落が生じた場合はエラーを表示して停止します。

## 登録音

`templates.npz` はユーザーが確認した録音から作成した周波数特徴です。元の16分超の録音や音声ファイルはリポジトリに含めていません。

- `match`: 録音の964.08〜964.62秒
- `stadium`: 録音の972.94〜976.94秒（③の冒頭4秒）

日本語の今回の録音に合わせたテンプレートです。言語・音声設定・ゲーム更新・ほかの音との重なりによっては検知できないことがあります。登録素材での再生試験は実戦での精度保証ではありません。

## 確認結果

提供された997.5秒の録音を解析し、独立検知モードでは964.7秒に②、977.0秒に③を検知しました。通常の30秒抑制では通知は1回です。

- 冒頭33秒の①など: 検知なし（最大一致度: ②0.629 / ③0.790）
- ②・③を別々に、音量25%・開始位置ずらし・少量のノイズを加えて再生: 両方検知（約0.976）
- 無音、ランダムノイズ: 検知なし
- 2つの別プロセスで600 Hzと1800 Hzを同時再生し、選択した600 Hzの音だけ取得（除外側の振幅は選択側の約0.02%以下）。PC全体の音声には両方が入ることも同時確認
- 実際のOverwatchからの音声取得・停止を確認
- 無音時の停止、ゲーム相当プロセスの終了、不正なPIDに関する3つの統合テストが成功

まだ別の実戦マッチでの検証は行っていません。

16-bit PCM WAVをオフライン確認する場合:

```powershell
.venv\Scripts\python.exe detector.py recording.wav
# ②と③を個別に確認したい場合
.venv\Scripts\python.exe detector.py recording.wav --cooldown 0
```

オフライン解析は音声全体をメモリに読み込みます。長い録音は事前に切り出してください。通常のリアルタイム監視は短いバッファのみ使用します。


## 音声ヘルパーのビルドとテスト

`ProcessAudio.cs` がネイティブ音声APIとの橋渡しを行い、16 kHz / mono / 16-bit PCMをパイプでPythonへ渡します。ゲームへのDLL注入やメモリ読み取りは行いません。`ProcessAudio.exe` は同梱ソースからビルドしたものです。修正後は `build-audio.bat` で再ビルドしてください。exeがない場合は `start.bat` から自動ビルドします。

```powershell
.venv\Scripts\python.exe -m unittest test_process_audio -v
```
